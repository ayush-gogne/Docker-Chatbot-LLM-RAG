To run our project: 

-first make sure you have Python 3 or higher installed\n
-install all the required packages by running pip install -r requirements.txt because we put all the necassary libraries you need to download in the text file so its easier\n
-install Ollama\n
-Download the Llama 3.2 model by running ollama pull llama3.2\n
-collect the docker documentation by running python collect_documents.py in the terminal\n 
-start the chatbot by running rag_system.py\n
-You can then ask questions and the chatbot will answer. type exit to end it\n
-To evaluate the chatbots responses vs what it is supposed to be run the command python evaluate.py\n
